This webpage provides results from the supplied demo, which is used by System Guide.

This demo was created July 2026 using 2 chromosomes from Ensembl Arabipdopsis and 2 from NCBI Brassica rapa. The draft demo is a simulated draft from the 2 chromosome sequences of Brassica rapa.

The demo that is provided with the SyMAP tarball has the projects demoArab, demoBrap and demoDraft.

The project demoDraft.demoBrap was created with ordered contigs, as described in Draft.

Two complete genomes: demoArab to demoBrap2

This section discusses the demoArab to demoBrap synteny, which represent complete genome sequences.

There are a variety of clustering&synteny computation options, as discussed in Pair Parameters. The following shows the Dot Plot and Summary using the following:

  • Cluster Algo1 (original modified) or Cluster Algo2 (exon-intron): The second is recommended when there is good gene annotation provided.

  • Synteny Original or Synteny Strict: The second is recommended for complete genome sequence; it does not perform well for draft.

Cluster Algo1 (original modified) and Synteny Original
Cluster Algo2 (exon-intron) and Synteny Strict

There is very little difference between the Dot Plots. The difference in the synteny algorithm are obvious on the more complicated examples, as shown in Synteny Results.

Draft: demoDraft to demoBrap

The demoDraft was run against the demoBrap with its order_against parameter set to draft->demoBp; this is explained in the System Guide. The resulting dot plot is shown on the right. Note that the 36 contigs are ordered, but still fragmented.

  
When the ordering algorithm is run, it creates a new project called demoDraft.demoBrap, where the 36 contigs are written into three chromosomes; the first two correspond to chr02 and chr06 of demoBrap. If there were any contigs that do not align, they would be assigned to chr0.

The new project demoDraft.demoBrap was aligned with demoBrap, resulting in the dot plot shown on the right.

Self-synteny: demoBrap

demoBrap has been run against itself. The blocks below the diagonal are mirrored above the diagonal, e.g. 02.06.3 and 06.02.3 are the same.
