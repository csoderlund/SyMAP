This page describes creating project protein files, running blast, and loading a file of blast results.
→ It is necessary to have loaded the GFF file with the CDS option (v5.8.7 or later); see Exon/CDS for details.
→ The xToSymap program started including CDSs in the GFF file in release v5.8.6.

Pros: (1) Loading a blast file is much faster than SyMAP running MUMmer. (2) Any numbers of blast file hits can be 'added' to the existing hits, including to MUMmer hits.

Cons: (1) It does not work if one of the genomic sequence is not annotated and it does not perform gene discovery. (2) It loses the exon/intron alignment coordinates, hence, the alignment to the 2D exon/intron structure is incorrect. (3) The user must obtain and manually run Blast or Diamond.

Pro/Con: SyMAP filters MUMmer hits whereas Blast hits are not filtered. However, the user can pre-filter the Blast file as they desire.

The steps are very easy:

  • Export the protein sequences from SyMAP (you must use the SyMAP exported proteins).
  • Run Blast or Diamond on them and put the results in data/seq_results/<proj1>_to_<prot2>/blast.
  • Set the Load Blast files from Parameters, then run Selected Pairs.
Please read the following for the details.

Create protein files

  1. On the Manager project's last line, it should say CDSs: (as shown on the right). If it says Exons:, see Parameters and reload the annotations with CDS.

  2. Select View for the project, then Export.
    Select the Export proteins option, then Export.

    This can take awhile, e.g. for the demoArab 13,476 genes, it took 15m:36s on my old MacOS x86_64 and 4m:28s on my newer MacOS M4. It uses a single CPU and does not use much memory.

  3. Likewise, export the proteins from the second project.
By default, the protein files will be in the SyMAP /export directory. The FASTA header line uses the value of GFF file attribute ID=; see Annotation file.

Create Blastp file

SyMAP does not run Blast or Diamond for you. You must download Blast or Diamond.

The output file must be the tabular format (-outfmt 6).

When SyMAP loads the hits, it does not filter them. Hence, you should have Blast or Diamond only produce the top 5 hits per gene (-max_target_seqs 5).

Load Blast files

Start SyMAP and select Pair Parameters. Select the Load Blast files option.
When you select Save, the directory data/<proj1>_to_<proj2>/blast will be created.
Exit SyMAP, move the blast tab file(s) to data/<proj1>_to_<proj2>/blast, restart SyMAP and select Selected Pair (see popup on the right).

SyMAP will load the blast hits, then execute the Collinear algorithm and the Synteny algorithm.

SyMAP will load ALL files in the /blast directory.
  • The hits coordinates are start=(1st CDS_start + blast_hit_start), end=(1st CDS_start + blast_hit_len). That is, it does not align correctly with the exons.
  • If a hit between a gene pair already exists in the database, only the Hit Type column will be updated to indicate that the hit was found in multiple files.
  • Only one hit per gene pair from a file will be loaded unless there are hits that do not overlap.
  • The blast hits are not clustered like the MUMmer hits are.

Add to existing hits

  • In order to load both MUMmer and Blast hits, first run SyMAP with MUMmer. Then add the Blast hits.
    The collinear and synteny algorithms run each time; the additional hits slow these down. But as Timings shows, these do not take a long time.

  • The Load&Synteny can be executed with any number of blast files. However, it does NOT check if a file is already loaded.

  • MUMmer, Blast and Diamond produce different subsets of gene pair hits. Moreover, Blast and Diamond produce different subsets depending one whether species1 is the database or species2. By loading all variations, the maximum number of gene pair hits will be in the SyMAP database. However, Blast and Diamond can produce some low quality hits.

Remove hits from a given file: There is no way to do this. Clear Pair then reload the desired files.

Example and Details

By default, the protein files were written to /export.

Diamond: To run diamond on the demo files: 

   cd export
   diamond makedb --in demoBrapPr.faa -d brapdb
   diamond blastp -q demoArabPr.faa -d brapdb  -o diam.b6 -f 6 -k 5 -p 4
   mv diam.b6 ../data/seq_results/demoArab_to_demoBrap/blast

Blast: The downloaded executables worked find. To run blast on the demo files: 

   cd export
   makeblastdb -in demoBrapPr.faa -dbtype prot -out brapdb
   blastp -query demoArabPr.faa -db brapdb -out blast.b6 -outfmt 6 -max_target_seqs 5 -num_threads 4
   mv blast.b6 ../data/seq_results/demoArab_to_demoBrap/blast
