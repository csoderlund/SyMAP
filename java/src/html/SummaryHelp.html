Explain Summary

Clustered hits (CH) have n≥1 MUMmer hits that may have gaps between them or overlap.
SubHit (SH) is a MUMmer hit that is part of a clustered hit.
Synteny Block (B) is composed of clustered hits.
Exon or CDS (EX) either the exons or CDSs were loaded; the term 'exon' is generally used here.

Key: Genome(G) Gene(GN) Exon(EX) Cluster Hit(CH) SubHit(SH) Block(B) CH in Block(CHB)

Covered by (c) - percent aligned bases. Aligned to (a) - regardless of cover.
e.g. GcGN genome covered by genes measured in the percent of aligned bases
       GNaCH genes aligned to clustered hits, where the coverage can be small, e.g. 1%

Genome and Annotation
#Genes Number of genes
GcGN Approximate coverage of the genome by genes; it does not take into account overlapping genes
AvgLen Average length of genes
MaxLen Length of the longest gene

The following uses the term 'exon' even if CDSs have been loaded.
GcEX Approximate coverage of the genome by exons; it does not take into account overlapping exons
AvgLen Average length of exons
MaxLen Length of the longest exon
#Seqs Total number of sequences (e.g. Chr) loaded for the project
Length Total length of the genome sequence

#Rev Number of clusters with opposite strand hits, i.e. +/- and -/+
g2 Number of cluster hits that align to a gene on both sides
g1 Number of cluster hits that align to a gene on one side
g0 Number of cluster hits that align to zero genes
AvgId Average percent identity
AvgSim Average percent similarity
#SubHits Number of MUMmer hits within the clustered hits
AvgNum Average number of subhits per cluster

Percent of exon bases that are covered by clustered hits - Algo2 only
GNaCH

Percent of clustered hits that align to at least part of a gene
For both GNaCH and CHaGN, the gene and hit coverage does not matter, e.g. it could be 1%.
GcCH*

Synteny Blocks

Inv Number of inverted blocks; note, blocks may contain local regions of opposite orientation

GcB*
≥2x 		Percent of genome bases covered by synteny blocks

Collinear Sets

Reproducing these numbers

NoWay: there is 'no way' to compute the associated statistic in SyMAP; it can only be computed using MySQL.
Most of the rest of the explanations use the Queries.
 
Genome and Annotation
#Genes Project Manager
GcGN Queries: Filter: Single All genes, project #1 only; select columns Glen; export to Excel;
sum the length and take its percentage of the genome length. Repeat for project #2.
AvgLen Queries: list all genes and lengths for a project; export to Excel; average the length.
MaxLen Queries: list all genes and lengths for a project; sort on length.
#Exons NoWay: This information is not available from SyMAP, except by viewing every gene popup on the 2D.
GcEX NoWay: There is no way to compute these numbers for exons without MySQL.
#Seqs Project Manager
Length Project Manager
Clustered Hits 1st table
#Clusters Queries: show all hits (no filter).
#Rev Queries: show all hits, sort on column Hit St, sort != to the top,
then find what row changes from != to ==.
CHB Queries: Filter In Block Yes. Take the percent of #rows/#Clusters.
g2 Queries: Filter Annotated Both.
g1 Queries: Filter Annotated One.
g0 Queries: Filter Annotated None.
AvgId Queries: shows all hits; display column Hit %Id; export to Excel;
compute average of the Hit %Id column.
AvgSim Same as above, but use the Hit %Sim column.
#SubHits Same as above, but use the Hit #Sub column and sum them.
AvgNum Same as above, but use the Hit #Sub column and average them.
Clustered Hits 2nd table
GNcCH This is a complex MySQL statement. It can be approximated as follows:
Queries: Filter Every*; sort on %Olap for project#1; export to Excel;
compute the average %Olap for all rows that have a gene for project#1.
Repeat for project#2.
EXcCH For Algo2, the above calculation will give you EXcCH; to get GCcCH:
      start SyMAP with '-go' will use the gene %Olap.
For Algo1, will be GNcCH. Algo1 does not have exon overlap (EXcCH).
GNaCH Queries: Filter Every*; from the Stats table, take the Genes: number;
take the percentage of it divided by the #Genes
CHaGN Queries: Filter Every; from the Stats table, take the Annotated: number;
take the percentage of it divided by the #Clusters
GcCH NoWay: This uses an algorithm that takes into account overlapping hits,
which is not available as a SyMAP query.
GcSH NoWay: Same as CHcG.
SubHit NoWay: The subhits are available for the 2D hit popup,
but there is no easy way within SyMAP to compute these numbers.
Synteny Blocks
#Blocks Circle: states the number of blocks and inverted blocks at the bottom.
Inv Same as above.
GNaCHB Queries: Filter: Block hits, Every* Gene; take the percentage of Stats Genes:/#Genes.
GcB (≥2x) NoWay: This uses an algorithm that takes into account block overlap.
Size range View the Report Blocks Plus option, and these numbers can be manually
computed from that.
Collinear Sets
Size range Queries: Filter: Collinear Set =N; view the Stats Collinear number.
