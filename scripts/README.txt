These scripts are part of the xToSymap interface.
See https://csoderlund.github.io/SyMAP/input/index.html

They are here in case they need to be edited:

ConvertNCBI.java    - converts NCBI genomic FASTA and .gff files to SyMAP input
ConvertEnsembl.java - converts Ensembl genomic FASTA and .gff files to SyMAP input
See https://csoderlund.github.io/SyMAP/input/index.html#edit

lenFasta.pl - prints the summary of the lengths of sequences in a fasta file,
	which is useful for draft genome sequences to determine minsize cutoff.
